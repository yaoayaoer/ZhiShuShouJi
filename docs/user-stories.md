# V1 用户故事

## US-001 用户注册

### 用户故事

作为一名新用户，我希望使用邮箱、用户名和密码注册账户，以便保存自己的书籍、阅读进度和笔记。

### 验收条件

- 用户必须填写用户名、邮箱和密码
- 邮箱必须符合正确格式
- 邮箱不能重复注册
- 用户名不能为空
- 密码长度不得少于 8 位
- 密码必须加密存储，不能保存明文
- 注册成功后返回用户基本信息
- 返回内容不能包含密码或密码摘要
- 参数不合法时返回明确的错误信息

### V1 暂不支持

- 手机号注册
- 邮件验证码
- 微信、QQ等第三方登录


## US-002 用户登录

### 用户故事

作为一名已注册用户，我希望使用邮箱和密码登录，以便访问自己的阅读数据。

### 验收条件

- 用户可以使用已注册邮箱和正确密码登录
- 登录成功后返回访问令牌
- 用户可以使用访问令牌访问受保护接口
- 邮箱或密码错误时返回统一提示
- 未登录用户不能访问个人书架、笔记和统计数据
- 已禁用或不存在的账户不能登录
- 返回内容不能包含密码或密码摘要

### V1 暂不支持

- 手机验证码登录
- 第三方账号登录
- 多设备管理
- 找回密码


## US-003 创建书籍

### 用户故事

作为一名读者，我希望录入一本纸质书的基本信息，以便将它加入个人书架并记录阅读过程。

### 验收条件

- 用户登录后才能创建书籍
- 书名为必填项
- 作者、ISBN、出版社、封面和总页数为可选项
- 总页数必须是正整数
- ISBN 如果填写，必须符合系统规定的格式
- 创建成功后返回书籍信息
- 创建时间和更新时间由系统记录
- 用户可以查看自己创建或使用的书籍信息

### V1 暂不支持

- 扫描ISBN自动识别
- 调用第三方图书信息接口
- 自动获取图书封面
- 批量导入书籍


## US-004 管理个人书架

### 用户故事

作为一名读者，我希望将书籍加入个人书架并管理阅读状态，以便了解自己想读、在读和已经读完的书。

### 验收条件

- 用户可以将书籍加入个人书架
- 同一本书不能重复加入同一用户的书架
- 阅读状态包括：想读、在读、读完和搁置
- 用户可以修改书籍的阅读状态
- 用户可以查看自己的全部书架记录
- 用户可以按阅读状态筛选书籍
- 书架列表支持分页
- 用户只能查看和修改自己的书架
- 用户可以将书籍从个人书架中移除
- 移除前应明确相关阅读记录和笔记的处理规则

### V1 暂不支持

- 公开展示他人书架
- 借阅管理
- 书籍交易
- 社交分享


## US-005 更新阅读进度

### 用户故事

作为一名正在阅读纸质书的用户，我希望记录当前阅读页码，以便下次继续阅读并了解阅读进度。

### 验收条件

- 用户只能更新自己书架中书籍的阅读进度
- 当前页码必须大于或等于 0
- 已知总页数时，当前页码不能超过总页数
- 更新进度后记录最后阅读时间
- 系统能够计算阅读进度百分比
- 总页数未知时不计算百分比
- 用户可以查看当前页码和最近更新时间
- 用户可以记录一次阅读的开始页和结束页
- 结束页不能小于开始页
- 非法页码不能保存

### V1 暂不支持

- 自动识别阅读页码
- 阅读计时器
- 后台自动记录阅读时长


## US-006 添加摘录或想法

### 用户故事

作为一名读者，我希望为正在阅读的书添加摘录和个人想法，以便以后回顾书中的内容和自己的思考。

### 验收条件

- 用户只能给自己书架中的书籍添加笔记
- 笔记类型包括摘录和想法
- 笔记内容不能为空
- 用户可以填写对应页码
- 页码必须大于 0
- 已知总页数时，页码不能超过总页数
- 用户可以填写章节名称
- 用户可以修改自己的笔记
- 用户可以删除自己的笔记
- 系统记录笔记的创建时间和更新时间
- 用户不能查看、修改或删除其他用户的私人笔记

### V1 暂不支持

- 图片摘录
- OCR文字识别
- AI自动总结
- 语音笔记
- 笔记公开分享


## US-007 管理标签

### 用户故事

作为一名读者，我希望为笔记添加标签，以便按照主题整理和查找笔记。

### 验收条件

- 用户登录后可以创建标签
- 标签名称不能为空
- 标签名称应去除首尾空格
- 同一用户不能创建同名标签
- 不同用户可以拥有同名标签
- 一条笔记可以关联多个标签
- 一个标签可以关联多条笔记
- 用户可以查看自己的标签列表
- 用户可以修改标签名称
- 用户可以删除自己的标签
- 删除标签不能同时删除关联的笔记
- 用户不能使用或修改其他用户的标签

### V1 暂不支持

- 标签层级
- 系统推荐标签
- 公共标签库
- 自动提取标签


## US-008 查询笔记

### 用户故事

作为一名读者，我希望按照书籍、标签和关键词查询笔记，以便快速找到以前记录的内容。

### 验收条件

- 用户只能查询自己的笔记
- 用户可以查看全部笔记
- 用户可以按书籍筛选笔记
- 用户可以按标签筛选笔记
- 用户可以按笔记类型筛选
- 用户可以使用关键词查询笔记内容
- 多个查询条件可以组合使用
- 查询结果支持分页
- 用户可以按创建时间或更新时间排序
- 默认按照最新创建时间倒序排列
- 没有匹配结果时返回空列表
- 查询条件不合法时返回明确错误信息

### V1 查询范围

关键词查询以下内容：

- 摘录内容
- 想法内容
- 章节名称

### V1 暂不支持

- Elasticsearch全文检索
- 拼音搜索
- 模糊语义搜索
- AI问答
- 搜索历史推荐


## US-009 查看阅读统计

### 用户故事

作为一名读者，我希望查看简单的阅读统计，以便了解自己的阅读情况。

### 验收条件

- 用户登录后才能查看阅读统计
- 统计数据只能包含当前用户的数据
- 用户可以查看书架中的书籍总数
- 用户可以查看想读、在读、读完和搁置的书籍数量
- 用户可以查看笔记总数
- 用户可以查看摘录数量和想法数量
- 用户可以查看累计阅读页数
- 没有阅读数据时，各项统计值返回 0
- 统计结果应与实际书架、阅读记录和笔记数据一致

### V1 暂不支持

- 用户排行榜
- 好友阅读对比
- 阅读趋势预测
- AI阅读报告
- 复杂图表分析
